# Сборка LONG PIG 3.0.2

Понадобятся Python 3.10 или новее, Blender 5.1 с включённым Sollumz 2.9 и доступным нативным экспортом Gen8, а также локальная установка GTA V Legacy. Команда ниже запускается из корня проекта в PowerShell. Укажите свой путь к игре и новую папку для результата.

```powershell
py tools/build.py --gta 'D:/Games/GTAV' --blender 'C:/Program Files/Blender Foundation/Blender 5.1/blender.exe' --output './out/3.0.2'
```

**Установочный ресурс** появится в `out/3.0.2/gabagool_sons_mlo/`. Для установки скопируйте эту папку в каталог ресурсов FiveM и добавьте `ensure gabagool_sons_mlo` в `server.cfg`.

**Редактируемые сцены Blender** появятся в `out/3.0.2/project/source/blender/`.

- `prototype/gs_prototype_mlo.blend` содержит интерьер и расстановку объектов.
- `props/lp_props.blend` содержит интерактивные предметы.
- `shutters/lp_shutters.blend` содержит ставни.

Параметрическая геометрия, исходные текстуры и клиентские скрипты находятся в `source/`. При повторной сборке скрипты заново генерируют сцены. Для постоянного изменения полок редактируйте `source/scripts/gs_v302_shelf.py`, для отделки — `gs_v302_finish.py`. Параметры освещения находятся в `source/fivem/gabagool_sons_mlo/lp_timecycle.xml`.

Скрипт читает одиннадцать нативных файлов квартала и три словаря LOD из игровых архивов. Он создаёт локальные производные файлы для открытых входов, коллизии и дальней видимости. Вся запись идёт в выбранную папку сборки. Готовые установочные архивы предыдущих версий для этого не требуются.

После экспорта скрипт проверяет состав ресурса, открывает созданные нативные модели, проверяет треугольники, комнаты и порталы. Положение 70 сигаретных пачек проверяется по игровым моделям и поверхностям полок. Результаты находятся в `out/3.0.2/verification.json`, подробности по отдельным стадиям — в `out/3.0.2/project/docs/_raw/`.
